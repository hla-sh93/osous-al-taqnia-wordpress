# تثبيت موقع أسس التقنية على ووردبريس

الإصدار 0.2.0

## محتويات الحزمة

| الملف | الوصف |
|---|---|
| `osous.zip` | قالب الموقع: جميع الصفحات، والمدونة، ونموذج التواصل، وصفحة الخطأ 404 |
| `osous-site.zip` | الإضافة المرافقة: تعزيز الحماية وتنظيف ترويسة الصفحات |
| `screenshot.png` | صورة القالب كما تظهر في قائمة المظهر ← القوالب |
| `source/` | الشيفرة المصدرية الكاملة وأدوات البناء والفحص (للمطورين) |

## المتطلبات

- ووردبريس 6.5 أو أحدث (جرى الاختبار على الإصدار 7.1)، و PHP 8.1 أو أحدث.
- ضبط الروابط الدائمة على **اسم المقالة** (الإعدادات ← الروابط الدائمة).
- حد رفع لا يقل عن **32 ميغابايت**، إذ يبلغ حجم ملف القالب نحو 14 ميغابايت بسبب صور
  الموقع. وإن كان حد الاستضافة أقل، يُطلب من مزود الاستضافة رفعه، أو يُرفع مجلد `osous`
  إلى `wp-content/themes/` عبر SFTP.

## قبل التثبيت على موقع منشور

يُنصح بأخذ نسخة احتياطية كاملة من الملفات وقاعدة البيانات. ينشئ التثبيت الصفحات غير
الموجودة، أما الصفحة الموجودة مسبقاً بالعنوان نفسه فتُستخدم كما هي مع الحفاظ على معرّفها
وعنوانها. ولا يُحذف أي محتوى.

## الخطوات

1. **الإضافة:** الإضافات ← أضف إضافة جديدة ← رفع إضافة ← اختيار `osous-site.zip` ←
   التنصيب الآن ← تفعيل.
2. **القالب:** المظهر ← القوالب ← أضف قالباً جديداً ← رفع قالب ← اختيار `osous.zip` ←
   التنصيب الآن ← تفعيل.
3. **الصفحات:** يثبّت التفعيل صفحات الموقع الست والستين تلقائياً، ويحدد الصفحة الرئيسية
   وصفحة المدونة. وتعرض صفحة المظهر ← **صفحات الموقع** عدد الصفحات المثبّتة، ويعيد زر
   **تثبيت الصفحات** العملية متى لزم.
4. **الروابط الدائمة:** الإعدادات ← الروابط الدائمة ← اسم المقالة ← حفظ.
5. فتح الصفحة الرئيسية وعدد من الصفحات للتأكد.

## بعد التثبيت

- **نموذج التواصل:** تصل الرسائل إلى البريد الإداري للموقع (الإعدادات ← عام). ويُنصح بضبط
  خادم بريد SMTP عبر إضافة مخصصة لضمان وصول الرسائل.
- **إضافات التخزين المؤقت:** تطلب صفحة التواصل عدم تخزينها مؤقتاً، وإن تجاهلت إضافة
  التخزين ذلك، يُستثنى العنوان `/contact/` من التخزين.
- **إضافة تحسين محركات البحث (اختيارية):** يطبع القالب عنوان كل صفحة ووصفها ووسوم
  المشاركة، وعند تفعيل Yoast SEO أو Rank Math أو All in One SEO أو The SEO Framework
  تتولى الإضافة ذلك.
- **المدونة:** تظهر المقالات الموجودة تلقائياً في صفحة المدونة بتصميم الموقع.

## ملاحظات

- يأتي محتوى الصفحات مع القالب في هذا الإصدار، ولا يُعدَّل من لوحة ووردبريس بعد.
- بعض صفحات التصميم الأصلي بلا وصف لمحركات البحث، ويمكن إضافته عبر إضافة تحسين محركات البحث.
